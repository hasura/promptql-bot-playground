# promptql-bot-playground

Fun PromptQL bots to share with people. Each folder is one self-contained bot / app artifact — clone it, read its README, run it on a bot VM. Recommended config targets the [Playground Project](https://prompt.ql.app/project/hasuraql/promptql-playground).

## Bots

- **hotel-lobby-remix**: "Hotel Lobby, but it's you two" — add two face photos, press Generate; Higgsfield Genjutsu swaps you into the viral orange-room *Hotel Lobby* clip and re-muxes the original audio.
